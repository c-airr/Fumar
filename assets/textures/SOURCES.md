# Textures

Every file here is **CC0 1.0** - public domain. No attribution is required and
no licence travels with them, which is why these can live in the repository and
ship inside a release while `assets/DamagedHelmet.glb` beside them cannot.

Only the colour map of each material is kept. fumar's shading reads base colour
and nothing else so far, and carrying normal, roughness and displacement maps
the renderer would ignore would be several megabytes of dead weight. They are
one download away if and when the shading grows to use them.

Each was re-encoded to JPEG at quality 82, which took the three from roughly
3 MB to 500 KB with no difference visible at the size they are drawn.
